\subsection{Neural networks}\label{subsec:neural-networks}

% - Start with your existing sentence: a single neuron is linear or logistic regression,
% depending on $f$. The limitation is that the features $X$ are fixed.
% A network instead learns the features passed to that final layer.

Linear and logistic regression share a common limitation: both act on a fixed
design matrix $\bm{X}$, so the model can only be as expressive as the features we
choose to put into it. A feed-forward neural network removes this limitation by
inserting one or more \emph{hidden layers} between the input and the output, each applying
a linear map followed by a non-linear activation. The final layer is then nothing more
than a linear or logistic regression, but it acts on features that are \emph{learned} from
the data rather than given in advance~\cite{hjorth-jensen_2026}.
% Since the parameters
% of these hidden layers enter the cost function non-linearly, there is no closed-form
% solution, and the network must be trained with gradient-based methods, computed by
% backpropagation.

\subsubsection{The artificial neuron}\label{subsubsec:artificial-neuron}

An artificial neuron computes a linear predictor, as in logistic regression, followed
by an activation function. We number layers as $l =0,1,\dots,L$, with $l=0$ the input and
$l=L$ the output, and $M_l$ the number of nodes in layer $L$. For a single neuron $j$ in
layer $l$, the activation is
\begin{equation}\label{eq:single-activation}
    z_j^l = \sum_{i=1}^{M_{l-1}} w_{ij}^l a_i^{l-1}+b_j^l,
\end{equation}
where $w_{ij}^l$ is the weight connecting node $i$ of layer $l-1$ to node $j$ of layer $l$,
and $b_j^l$ is the bias of node $j$ in layer $l$. We can then obtain the output by applying
the activation function~\cite{hjorth-jensen_2026},
\begin{equation}\label{eq:single-activation-function}
    a_j^l = f(z_j^l).
\end{equation}
This whole process is depicted in \cref{fig:single-artificial-neuron}, where the activation
and output of a single neuron $j$ in layer $l$ is shown.

\subsubsection{Forward pass}

We can write the activation and output of all neurons the layer $l$ in matrix-form,
where \cref{eq:single-activation,eq:single-activation-function} become
\begin{equation}\label{eq:matrix-form-activation}
    \bm{z}^l = (\bm{W}^l)^\top \bm{a}^{l-1} + \bm{b}^l,
    \qquad \bm{a}^l = \bm{f}(\bm{z}^l),
\end{equation}
with $\bm{f}$ applied element-wise. Evaluating \cref{eq:matrix-form-activation}
sequentially for all $l$-values is the feed-forward pass and returns the network
output $\bm{\tilde{y}}=\bm{a}^L$~\cite{hjorth-jensen_2026}.

    \centering
    \includestandalone[width=0.8\linewidth]{figures/tikz/dense-neural-network}
    \caption{Illustration of a fully connected feed-forward neural network.
    Adapted from \textcite{love_2024}.}
    \label{fig:neural-network-tikz}
\end{figure}

We can further collect the weights and biases into a single parameter vector
$\bm{\Theta}=\{\bm{w}^l, \bm{b}^l\}_{l=1}^L$, and write the optimization problem as
\begin{equation}\label{eq:nn-optimization-problem}
    \hat{\bm{\Theta}} = \arg \min_{\bm{\Theta}} C(\bm{\Theta}), \quad
    C(\bm{\Theta}) = \frac{1}{n} \sum_{i=1}^n L(y_i, \tilde{y}_i) + \lambda \Omega(\bm{\Theta}),
\end{equation}
where $L$ is the cost function and $\Omega$ is the regularization term~\cite{hjorth-jensen_2026}.
This is a non-convex optimization problem, so there is no closed-form solution, and we must
resort to the gradient-based methods reported in \cref{subsubsec:gradient-descent} to find
a local minimum.

\subsubsection{Activation functions}

% Introduce why it must be non-linear and why we care about the derivative
% Element-wise (done for all $z$ in $\bm{z}$). Should we write z or \bm{z} below?

% Activation functions. First explain why they must be nonlinear: stacked linear layers
% collapse into one linear map. Then cover why the derivative matters, which leads into
% backprop. Then sigmoid, ReLU and leaky ReLU, including vanishing gradients and
% saturation as the argument for ReLU.

The activation function must be non-linear and differentiable almost everywhere.
If it were linear, the composition of multiple layers would collapse into a single
affine transformation, and the network would be no more expressive than a single
layer~\cite{hjorth-jensen_2026}.
Our study will revolve around the following three activation functions:

\paragraph{Sigmoid} The logistic or sigmoid function is given by
\begin{equation*}\label{eq:sigmoid}
    \sigma(z) = \frac{1}{1+e^{-z}}, \qquad \sigma'(z) = \sigma (z) (1 - \sigma (z)),
\end{equation*}
and was the standard choice for decades. Its main drawback is that it saturates for
large $|z|$, which leads to vanishing gradients and slow training~\cite{hjorth-jensen_2026}.

\paragraph{ReLU} The rectified linear unit (ReLU),
\begin{equation*}\label{eq:relu}
    \mathrm{ReLU}(z) = \max (0, z),
    \quad \mathrm{ReLU}'(z) =
    \begin{cases}
        1, & \text{if } z>0, \\
        0, & \text{if } z\leq 0,
    \end{cases}
\end{equation*}
is faster to compute, does not saturate for $z>0$, and is a sound default choice for hidden layers.
Its main drawback is that it can lead to dead neurons, which never activate and thus never learn~\cite{hjorth-jensen_2026}.

The leaky ReLU (LReLU) repairs this issue by allowing a small gradient for negative values,
so the gradient never completely vanishes. It is defined as
\begin{equation*}\label{eq:leaky-relu}
    \mathrm{LReLU}(z) =
    \begin{cases}
        z, & \text{if } z > 0, \\
        \alpha z, & \text{if } z \leq 0,
    \end{cases}
    \quad \alpha \approx 0.01,
\end{equation*}
and its derivative is
\begin{equation*}
    \mathrm{LReLU}'(z) =
    \begin{cases}
        1, & \text{if } z > 0, \\
        \alpha, & \text{if } z \leq 0.
    \end{cases}
\end{equation*}

\subsubsection{Backpropagation}

We can compute the gradient of the cost function with respect to the parameters using
the backpropagation algorithm~\cite{rumelhart_1986}. The key idea is to compute the
error at the output layer and then propagate it backward through the network.

The error is given by
\begin{equation*}
    \bm{\delta}^l = (\bm{W}^{l+1} \bm{\delta}^{l+1}) \odot \bm{f}'(\bm{z}^l),
\end{equation*}
where $\odot$ denotes the element-wise product, and $\bm{\delta}^l$ is the error at layer $l$.
For $l=L$, we don't have a next layer, but for the two natural pairings of output layer and
loss function (i.e., linear output with MSE loss and sigmoid output with binary cross-entropy loss),
we have $\bm{\delta}^L = \bm{a}^L - \bm{y}$~\cite{hjorth-jensen_2026}.
The gradients with respect to the weights and biases are then given by
\begin{equation*}
    \frac{\partial C}{\partial \bm{W}^l} = \bm{\delta}^l \bm{a}^{l-1}, \qquad
    \frac{\partial C}{\partial \bm{b}^l} = \bm{\delta}^l.
\end{equation*}

Finally, we can update the parameters using gradient descent:
\begin{equation*}
    \bm{W}^l \leftarrow \bm{W}^l - \gamma \frac{\partial C}{\partial \bm{W}^l}, \qquad
    \bm{b}^l \leftarrow \bm{b}^l - \gamma \frac{\partial C}{\partial \bm{b}^l},
\end{equation*}
where $\gamma$ is the learning rate.
